# 鱼油选择 fish-oil-selection 1.1.0

> 先看懂标签，再谈价格与品牌。

鱼油的包装上，数字多、标识多、宣传语更多：正面写着“500 EPA”，背面的每份却是三粒；浓度很高，价格也高，不知该不该买；瓶身印着几枚认证标志，又说不清各自管什么。这个 skill 想做的事，是把这些信息拆开、算清、查实，再给出有依据的选择理由。

fish-oil-selection 是给 AI 助手用的鱼油选购核对工具（skill），Claude 和 GPT 都可以使用。你提供产品照片、成分表、价格或官方检测资料，它帮你换算每粒 EPA 与 DHA、浓度和每克成本，核对 IFOS、NSF、USP 等认证的实际范围，比较鱼油、磷虾油与藻油，并把选购依据整理成一篇真实的空瓶笔记。

## 使用前必读

- **不代替诊断或处方。** 本 skill 帮你看懂标签、比较证据，不判断你该不该服用、服用多少。涉及疾病、用药、过敏或高剂量，请咨询医生或药师。
- **认证与检测要看到具体产品和批号。** 瓶身上的标志、品牌的会员身份、原料商的报告，都不等于这一瓶成品已通过独立检测。查不到报告也不等于检测失败，skill 会如实标为“待核实”。
- **价格、配方与认证会变。** 涉及当前配方、售价和认证状态时，skill 会要求查最新官方资料并附上链接与查询日期；无法联网时，只做能算的部分，其余标为待核实。
- **Claude 与 GPT 都能用。** 按 Claude Code 的 skill 格式编写，也在 ChatGPT 桌面应用里试用过：能读商品截图、换算含量、引用官方页面，数字与结论和 Claude 一致。其他 AI 工具没有测试，不保证。运行环境若不允许联网或执行命令，认证目录查询会标“没查成”，不会被写成“未认证”。

## 它能做什么

1. **建立产品事实表。** 品牌、完整型号、销售版本、每份粒数、鱼油总量、EPA、DHA、剂型、批号与有效期、实付价格，按实际瓶子逐项记录。
2. **统一单位后再计算。** 每粒 EPA＋DHA、EPA＋DHA 占鱼油比例、总 Omega-3 浓度、每瓶总量、每克成本，分子分母对应同一份量，两种“浓度”不混写。
3. **核实检测，而不是只认标志。** 区分品牌宣传、原料报告、成品检测与匹配批号的报告；分别说明 IFOS、NSF、USP、ConsumerLab、GOED 会员与 FDA 注册各自证明什么、不证明什么。
4. **看氧化与新鲜度。** 有报告时记录 PV、AV、TOTOX 及检测日期、批号和方法，并说明限值的适用范围，不设万能门槛。
5. **比较油种。** 鱼油、磷虾油、藻油先比实际含量、证据与成本，不因磷脂、虾青素、剂型等概念直接推出疗效优劣。
6. **按问题交付。** 单品解读、多款比较表、空瓶笔记，各有对应格式；证据不足时给条件性选择，不硬排唯一冠军。
7. **对照视频标准。** 按视频的浓度分档（EPA＋DHA 占鱼油的 30%、50%、85% 三个分界）和认证要求，另起一行写“按视频标准”，与本 skill 自己的判断分开，并注明这是视频观点。

## 它不做什么

- 不给个人的治疗剂量，不把营养摄入、补充剂用量与治疗剂量混为一谈。
- 不凭浓度、品牌名气或单个标识下结论。
- 不编造认证、检测结果、使用效果或复购决定；读不到的内容明确标为无法核实。
- 买前调研时不索要批号，也不追问到手价：价格按截图标价计算并注明页面标注，批次级检测项标“买前无法核对”。
- 不为任何品牌背书。

## 认证目录查询脚本

仓库附带两个只用 Python 标准库的小脚本，需要联网，用来查认证机构的公开目录：

```bash
# IFOS：品牌下登记了哪些产品；加 --product 时同时读批号与有效期
python3 scripts/ifos_lookup.py --brand "<英文品牌名>" [--product "<产品名关键词>"]

# NSF：膳食补充剂目录里的厂商与产品
python3 scripts/nsf_lookup.py --company "<英文厂商名>" [--product "<产品名>"]
```

- 两个脚本只接受英文名（目录本身用英文检索），名称至少 3 个字母。
- 退出码：0 查到，3 目录明确查无，2 出错。网络失败、页面改版、被拦截都按出错处理，不会被说成“查无”。
- “查无”只表示目录里没有以这个名称登记的条目，不代表产品未检测或不合格。品牌有登记，也不代表手上这一瓶在其名下。
- USP 的网站拒绝脚本访问，需用浏览器查询，步骤见 [SKILL.md](SKILL.md)。
- IFOS 的品牌检索用的是目录网页自身的接口，没有公开文档，改版后可能失效；失效时脚本报错退出。
- 测试不联网：`python3 -m unittest discover -s tests`。

## 安装

把本仓库放进所用工具的 skills 目录即可。

Claude Code：

```bash
git clone https://github.com/mildorbit804/fish-oil-selection ~/.claude/skills/fish-oil-selection
```

GPT（Codex，skills 目录默认为 `~/.codex/skills`）：

```bash
git clone https://github.com/mildorbit804/fish-oil-selection ~/.codex/skills/fish-oil-selection
```

之后在对应工具里提出需求，例如：

- “帮我看看这瓶鱼油的成分表，算一下每粒 EPA 和 DHA、每克成本。”
- “这三款鱼油怎么选？帮我列个对比表。”
- “这个瓶子上的认证标志是什么意思，能查到对应的报告吗？”
- “把我选这瓶鱼油的理由整理成一篇空瓶笔记。”
